# ⚪ Himpunan Kosong

**Himpunan kosong** adalah himpunan yang **tidak memiliki elemen sama sekali**.

Artinya, tidak ada satu pun anggota di dalam himpunan tersebut.

📌 Dalam matematika, himpunan kosong ditulis dengan simbol:  
- `{}`  
- atau `∅` (dibaca: kosong)

Karena tidak ada elemen di dalamnya, maka:

🔢 **Kardinalitas (jumlah anggota) dari himpunan kosong adalah 0**  
✨ Ditulis sebagai: `|∅| = 0`

---

## 📚 Contoh Himpunan Kosong:

1. **A = { x | x adalah bilangan genap yang lebih kecil dari 0 }**  
   👉 Tidak ada bilangan genap yang lebih kecil dari 0 (dalam himpunan bilangan asli)  
   ✅ Maka: `A = ∅`

2. **B = { buah yang berbentuk segitiga }**  
   👉 Sampai sekarang tidak ada buah yang berbentuk segitiga  
   ✅ Maka: `B = {}`

---

🎯 **Kesimpulan:**  
Himpunan kosong adalah himpunan **tanpa elemen apa pun**, dan dilambangkan dengan `∅` atau `{}`.  
Jumlah anggotanya selalu **nol**.
