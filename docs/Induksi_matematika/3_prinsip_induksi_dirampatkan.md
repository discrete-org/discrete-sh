# Prinsip Induksi yang Dirampatkan
Kadang-kadang kita ingin membuktikan bahwa pernyataan p(n) benar untuk semua bilangan bulat > n0, jadi tidak hanya bilangagan bulat yang dimulai dari 1 saja. Prinsip induksi sederhana dapat dirampatkan (generalized) untuk menunjukkan hal ini sebagai berikut:

Misalkan p(n) adalah pernyataan perihal bilangan bulat dan kita ingin membuktikan bahwa p(n) benar untuk semua bilangan bulat n > n0. Untuk membuktikan ini, kita hanya perlu menunjukkan. bahwa:
1. p(n0) benar, dan
2. jika p(n) benar maka p(n + 1) benar untuk setiap n > n0
