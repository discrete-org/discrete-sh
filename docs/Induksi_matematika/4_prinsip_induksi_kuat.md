# Prinsip Induksi Kuat
Kadang-kadang versi induksi yang lebih kuat diperlukan untuk membuktikan pernyataan mengenai bilangan bulat. Versi induksi yang lebih kuat adalah sebagai berikut:

Misalkan p(n) adalah pernyataan perihal bilangan bulat dan kita ingin membuktikan
bahwa p(n) benar untuk semua bilangan bulat n > n0. Untuk membuktikan ini,
kita hanya perlu menunjukkan bahwa:
1. p(n0) benar, dan
2. jika p(n0 ), p(n0 + 1), ..., p(n) benar, maka p(n + 1) juga benar untuk setiap bilangan bulat n > n0,

sehingga p(n) benar untuk semua bilangan bulat n > n0.
